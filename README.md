O MovieLoc é um sistema de locação de filmes desenvolvido com o objetivo de representar uma solução de software utilizando conceitos de Programação Orientada a Objetos (POO).

O sistema foi desenvolvido para organizar e gerenciar informações relacionadas a filmes, clientes e locações.
